Cockpit complet calé sur le module DCS : cold start (examen), radar, capteurs, armement, radios, HUD.
Commandes Quest (manettes) : viser + gâchette = vers l'avant / le haut / sens horaire · grip = vers l'arrière / le bas / anti-horaire · stick haut/bas/gauche/droite = idem · B ou Y = recentrer · A ou X = panneau d'examen.
Manette des gaz : viser une poignée + gâchette maintenue, puis avancer / reculer la manette (OFF → IDLE → MIL → cran A/B → MAX). Retour sur OFF : lever d'abord le finger lift (devant la poignée). Main : pincer la poignée et la déplacer. PC : cliquer-glisser la poignée vers le haut / bas. Les boutons des poignées (TDC, COMM, aérofreins, leurres, cage, antenne, RAID, ATC) sont cliquables.
Quest (mains) : appuyer du bout de l'index sur boutons et interrupteurs (le geste donne le sens), pincer + tourner le poignet pour les molettes.
PC : glisser pour regarder · clic gauche / droit sur une commande · molette = tourner.
HOTAS virtuel (Quest) : appui long sur le clic du stick d'une manette pour passer cette main en HOTAS (aide affichée au-dessus de la manette). Droite = manche : gâchette tir / laser, A pickle, B undesignate, B maintenu + stick = sélection d'arme, stick = SCS, grip maintenu = piloter au poignet. Gauche = manette des gaz : stick TDC, gâchette TDC enfoncé, grip maintenu = gaz, X COMM 1, Y COMM 2, Y maintenu + stick = élévation antenne, clic cage/uncage, grip+X leurres, grip+Y aérofreins, grip+clic RAID/FOV.
HOTAS clavier : flèches TDC · Entrée TDC enfoncé · Ctrl+flèches SCS · Alt+flèches sélection d'arme (↑ AIM-7, ↓ GUN, → AIM-120, ← AIM-9) · Espace gâchette · Maj+Espace largage · Retour undesignate · C cage · F RAID/FOV · X/Z leurres · B aérofreins · 1/2 COMM 1/2 · PgUp/PgDn gaz · W A S D manche · [ ] antenne · P palette A/P.
